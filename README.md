# Домашние задание к работе номер 7
## Условие Задачи
Дано целое число k, определить каким днем недели является k-й день невисокосного года, в котором 1 января приходиться на заданный заранее день недели.
## 1. Алгоритм и блок-схема
### Алгоритм:
1. Начало
2. Объявить переменные и запросить их ввод пользователем:
- **k** - день года;
- **jan** - день недели 1 января.
4. Объявить переменную для подсчёта дня недели:
- **weekday** - нахождение дня недели;
5. Написать оператор switch с 6-ю case-ами для вывода дня недели и default для вывода ошибки.
6. Конец.

## 2. Реализация программы
```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
	setlocale(LC_ALL, "RUS");

	int k;

	puts("Введите день:");

	scanf("%d", &k);

	int jan;

	puts("Введите день недели 1 января (1 - 7):");

	scanf("%d", &jan);

	int weekday = (jan - 1 + k - 1) % 7;

	switch (weekday)
	{
	case 0:
		puts("Понедельник\n");

		break;

	case 1:
		puts("Вторник\n");

		break;

	case 2:
		puts("Среда\n");

		break;

	case 3:
		puts("Четверг\n");

		break;

	case 4:
		puts("Пятница\n");

		break;

	case 5:
		puts("Суббота\n");

		break;

	case 6:
		puts("Воскресенье\n");

		break;

	default:
		puts("Ошибка определения дня недели\n");
	}

	return 0;
}
```
